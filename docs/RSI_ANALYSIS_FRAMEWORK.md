## 一、RSI 指标的本质

### 1.1 公式与含义

**RSI（Relative Strength Index，相对强弱指标）** 由 J. Welles Wilder Jr. 于 1978 年发明：

```
RS = N日内平均涨幅 / N日内平均跌幅
RSI = 100 - 100 / (1 + RS)
```

**核心含义**：
- RSI 衡量"买方力量 vs 卖方力量"的相对强弱
- 范围 [0, 100]，永不超出（本程序通过平滑处理保证在 (0, 100) 开区间内）
- 50 为多空平衡线

### 1.2 RSI 的多种用法（理论）

| 用法 | 说明 | 在 A 股的适用性 |
|------|------|----------------|
| **超买/超卖** | RSI > 70 超买（顶部信号），< 30 超卖（底部信号） | ⚠️ 牛市易钝化、需调整阈值 |
| **中轴穿越** | RSI > 50 多方占优，< 50 空方占优 | ✅ 适合趋势判断 |
| **背离** | 价格新高/新低但 RSI 没同向 → 反转预警 | ✅ 红利低波顶部钝化时极有效 |
| **失败波动** | RSI 的 M 头/W 底（40-50 区间反转） | ✅ Connie Brown 强调的中继信号 |
| **趋势线** | 在 RSI 上画趋势线（不是价格） | ⚠️ 主观性强，程序化难 |
| **多周期共振** | 多个周期 RSI 同时给出信号 → 强信号 | ✅ 程序化首选 |

### 1.3 周期选择

| 周期 | 特性 | 适用场景 |
|------|------|---------|
| **RSI6**（短线） | 敏感、噪声多 | 短线波段（持仓 3-10 天） |
| **RSI12**（中短线） | 平衡、券商标准 | 中短线波段（持仓 10-30 天） |
| **RSI24**（中线） | 平滑、信号少 | 中线波段（持仓 30-60 天） |

本程序默认计算 **6/12/24 三周期**（`data_calculator.py` 的 `calculate_rsi(periods=[6, 12, 24])`），为后续多周期共振分析提供数据基础。

## 二、红利低波指数上 RSI 的预期特性

### 2.1 H20269 的特殊性

H20269 是**红利低波全收益指数**，与传统宽基（沪深 300、上证 50）有显著差异：

1. **低波动**：成分股按"低波动"因子筛选，本身波动小
   - 预期：RSI 极值更少、范围更窄
2. **红利因子**：股息率提供"价值锚"
   - 预期：均值回归特性强（RSI 大幅偏离后易回归）
3. **大盘价值风格**：相对理性
   - 预期：情绪化极端（RSI > 90 或 < 10）罕见
4. **慢牛/慢熊特征**：趋势延续性强
   - 预期：RSI 钝化（长期停留在超买/超卖区）

### 2.3 关键预判（待数据验证）

**预判 1**：传统 70/30 阈值对 RSI12 过于宽松
- 估计 RSI12 > 70 约 8-10%，< 30 约 2-3%
- 如果用 70/30 做信号，触发太频繁（噪声多）
- **建议方向**：用 80/20 或 85/15 做超买/超卖阈值

**预判 2**：RSI 均值略偏多（54）
- 反映红利低波的"长期慢牛"特性
- **策略含义**：多头信号可以稍宽松，空头信号要更严
- 比如：买入阈值 30，卖出阈值 75（不对称）

**预判 3**：RSI24 极端值极少（<20 为 0%）
- 红利低波在 24 日尺度上几乎不会出现极端恐慌
- **策略含义**：用 RSI24 做中线信号可靠性低
- 可能需要用 RSI6/RSI12 为主，RSI24 作为趋势过滤

**预判 4**：底部 RSI 极值罕见且珍贵
- RSI12 < 20 只有 2 次（0.07%）
- 这些极值往往是历史大底（如 2015 股灾、2018 贸易战底）
- **策略含义**：极值出现时，信号可信度极高，应该重仓

## 三、为什么需要 RSI？长线策略的痛点

### 3.1 原 MA250 策略的特性

| 维度 | MA250 长线策略 |
|------|---------------|
| 持仓周期 | 长（数月到数年） |
| 年均交易次数 | 极少（5-10 次/年） |
| 卖出触发 | 乖离率 > 15%（罕见） |
| 适合市场 | 单边趋势市 |
| 弱点 | 震荡市"过山车"，错过中短线波段 |

### 3.2 MA250 策略的盲区（RSI 能补足的）

**盲区 1**：乖离率在 5%~12% 之间的波动
- 乖离率 8% 时，MA250 策略不卖（未到 15%）
- 但 RSI 可能已经 > 70，预示短线回调
- 可以做：**部分止盈**（如卖出 20%）

**盲区 2**：底部反弹的中段
- MA250 策略在跌破年线时全仓定投
- 但底部反弹时，乖离率仍 < 0，策略还在定投
- RSI 可能已经从 20 → 50（确认反弹），可以**加速建仓**

**盲区 3**：震荡市的频繁假突破
- 价格多次穿越 MA250，策略反复触发定投/卖出
- 用 RSI 的"中轴 50"作为趋势确认，可以过滤假信号

**盲区 4**：顶/底的"早期信号"
- MA250 是滞后指标，顶部确认往往晚 30-60 天
- RSI 是动量指标，**顶背离**可以在顶部前 10-30 天预警

### 3.3 加入 RSI 的目标

**不是替代 MA250，而是增强**：
1. **仓位管理更精细**：从"二档买卖（15%/17.5%）"到"多档调仓"
2. **捕捉中短线波段**：在长线持仓的基础上叠加波段交易
3. **提前预警顶/底**：用 RSI 背离捕捉 MA250 错过的拐点
4. **过滤假信号**：用 RSI 趋势确认减少震荡市的反复交易

## 四、RSI 特性分析框架（数据分析优先）

**核心原则**：**先用数据回答"RSI 在 H20269 上有什么特性"，再设计策略**。

### 4.1 分析维度一：RSI 分布统计

**目标**：搞清楚 RSI 在 H20269 上的"形态"

**分析项**：
1. **整体分布**：直方图（1% 粒度），百分位数（10/25/50/75/90/95/99）
2. **分位数表**：找出"超买/超卖"的真实分位阈值
   - 例如：RSI12 的 95% 分位可能是 76（而不是 70，实际 P95=76.03）
   - 用 78 做超买阈值，触发频率固定为 5%
3. **极值事件列表**：RSI12 历史前 20 高、前 20 低对应的时间和价格
4. **极值后续走势**：RSI 极值后 5/10/20/60 日的价格涨跌

**输出**：
- HTML 图：RSI 分布直方图（3 个周期叠加）
- MD 报告：分位数表、极值事件表

### 4.2 分析维度二：RSI 与未来收益的相关性

**目标**：搞清楚"当前 RSI 水平对未来收益的预测能力"

**分析方法**：
1. **分桶分析**：将 RSI 分成 10 个桶（0-10, 10-20, ..., 90-100）
2. **未来收益**：对每个桶计算未来 5/10/20/60 日平均收益
3. **可视化**：RSI 分桶 vs 未来收益的柱状图

**预期发现**（待验证）：
- RSI < 20 → 未来 20 日收益显著为正（超卖反弹）
- RSI > 80 → 未来 20 日收益显著为负（超买回落）
- RSI 40-60 → 未来收益接近 0（震荡无方向）
- U 型或 L 型曲线

**输出**：
- HTML 图：RSI 分桶 vs 未来收益（多周期对比）
- MD 报告：每个 RSI 桶的统计特征

### 4.3 分析维度三：RSI 与乖离率的二维分析

**目标**：搞清楚"两个指标的协同/矛盾信号如何解读"

**分析矩阵**（4 象限）：

| 乖离率 \ RSI | 低（< 30） | 中（30-70） | 高（> 70） |
|--------------|-----------|-------------|-----------|
| **高（> 10%）** | 顶部背离？ | 趋势强（持仓） | 顶部预警（减仓） |
| **中（0-10%）** | 回调低点（加仓） | 震荡（观望） | 短线超买（小止盈） |
| **低（< 0%）** | 极度恐慌（重仓） | 底部反弹（建仓） | 强势反弹（持有） |

**分析步骤**：
1. 计算每日 (乖离率分桶, RSI 分桶) 的二维分布
2. 对每个格子计算未来 20 日平均收益
3. 找出"高收益格子"和"低收益格子"

**预期发现**（待验证）：
- "双低"（乖离率 < -5% 且 RSI < 25）→ 未来收益极高（黄金机会）
- "双高"（乖离率 > 12% 且 RSI > 75）→ 未来收益极低（顶部预警）
- "矛盾象限"（乖离率高 + RSI 低）→ 需要判断是回调还是反转

**输出**：
- HTML 热力图：二维收益矩阵
- MD 报告：每个象限的统计

### 4.4 分析维度四：RSI 背离识别

**目标**：找出历史顶背离/底背离事件，验证有效性

**背离定义**：
- **顶背离**：价格创 N 日新高，但 RSI 未创新高（且 RSI 在高位 > 60）
- **底背离**：价格创 N 日新低，但 RSI 未创新低（且 RSI 在低位 < 40）
- N 通常取 20-60 日

**分析步骤**：
1. 识别价格的局部极值（如 20 日内最高/最低）
2. 对比对应 RSI 的极值
3. 记录所有背离事件
4. 分析背离后 5/10/20/60 日价格走势

**预期发现**（待验证）：
- 顶背离准确率（如 60-70%）
- 底背离准确率（如 60-70%）
- 背离事件的稀疏性（每年可能只有 2-5 次）

**输出**：
- HTML 图：价格 + RSI 双轴图（标注背离点）
- MD 报告：背离事件列表 + 准确率

### 4.5 分析维度五：多周期共振

**目标**：搞清楚"多个 RSI 同时给出信号的可靠性"

**共振定义**（示例）：
- **三周期共振超买**：RSI6 > 80 且 RSI12 > 70 且 RSI24 > 60
- **三周期共振超卖**：RSI6 < 20 且 RSI12 < 30 且 RSI24 < 40

**分析步骤**：
1. 识别共振事件（频率应该很低，每年 1-3 次）
2. 对比"单周期信号" vs "共振信号"的准确率
3. 设计基于共振的买卖规则

**输出**：
- MD 报告：共振事件统计 + 可靠性对比

### 4.6 分析维度六：RSI 与交易日的季节性

**目标**：搞清楚"RSI 在不同时间窗口的特性"

**分析维度**：
1. **年内季节性**：RSI 在 1-12 月的分布（红利低波有"年报行情"）
2. **月初/月末效应**：资金面紧张 vs 宽松
3. **跨年效应**：春节前后 RSI 特性

**预期发现**（待验证）：
- 红利低波在 1-4 月（年报季）RSI 偏高
- 6-8 月 RSI 偏低（"五穷六绝七翻身"）

**输出**：
- HTML 图：RSI 月度分布箱线图

## 五、中短线策略的架构选项

**重要说明**：以下 4 个选项是**候选方案**，不是已确定方案。需要完成第四章的数据分析后，根据数据结果选择最合适的方案。

### 5.1 架构 A：分层仓位制（推荐起步）

**核心思想**：
- 总资金分成两部分：**长线仓**（70%）+ **短线仓**（30%）
- 长线仓：原 MA250 策略管理（不动）
- 短线仓：RSI 策略独立管理（新加）

**信号冲突处理**：
- 长线卖出信号优先级最高 → 清仓所有（含短线）
- 长线买入信号优先级高 → 短线不动
- 短线信号仅在自己资金池内执行

**优点**：
- 清晰、可回测、易实现
- 长短线概念明确分离
- 可以单独评估"长线部分"和"短线部分"的贡献

**缺点**：
- 资金使用效率低（30% 资金长期只做短线）
- 短线策略可能错过牛市主升浪（长线在涨，短线在做波段）

**实现复杂度**：⭐⭐（较低）

### 5.2 架构 B：增强信号制（融合）

**核心思想**：
- 单一资金池（不分长短线）
- MA250 信号决定大方向（多/空）
- RSI 信号决定**精确定时**（什么时候买/卖）

**典型场景**：
- MA250 卖出信号触发（乖离率 > 15%）
- 但 RSI 还在 60，没到 70 → **等待 RSI > 70 再卖**（卖在更高点）
- 反之亦然：MA250 买入信号触发 + RSI 还在 40 → **等待 RSI < 30 再买**

**优点**：
- 资金使用效率最高
- 长短线概念融合，单一策略

**缺点**：
- 长短线概念模糊（什么时候算长线卖出？）
- 回测复杂（等待逻辑需要 timeout 机制）
- 可能错过最佳价格（等待 RSI 期间价格反向）

**实现复杂度**：⭐⭐⭐⭐（高）

### 5.3 架构 C：状态机增强（在原策略的"等待状态"加 RSI）

**核心思想**：
- 利用 MA250 策略的"等待状态"做短线
- 例如：triggered_a=True 期间（已卖 50%），用 RSI 做"高抛低吸"

**典型场景**：
- MA250 触发 a% 卖出（已卖 50%，剩 50%）
- 在等待 b% 期间，用 RSI 做短线：
  - RSI > 70 → 再卖 20%（局部止盈）
  - RSI < 30 → 回补 20%（局部低吸）
  - 等到 b% 触发 → 清仓

**优点**：
- 充分利用长线的"暂停期"
- 短线交易与长线仓位强相关
- 适合"主升浪末期"的复杂场景

**缺点**：
- 极其复杂（状态机嵌套）
- 短线交易可能干扰长线信号
- 回测和实盘验证难度高

**实现复杂度**：⭐⭐⭐⭐⭐（最高）

### 5.4 架构 D：纯独立短线（替代）

**核心思想**：
- 完全独立的 RSI 短线策略
- 不依赖 MA250
- 只用 RSI（可能加价格/成交量）做信号

**典型场景**：
- 用 RSI12 < 20 买入，RSI12 > 80 卖出
- 持仓 3-15 天
- 严格止损（-5%）

**优点**：
- 纯粹测试 RSI 有效性
- 易于回测和优化
- 可以并行运行（与 MA250 策略对比）

**缺点**：
- 脱离长线背景（没有趋势过滤）
- 容易逆势交易（熊市中超买信号频繁假）

**实现复杂度**：⭐（最低）

**阶段 2**：创建 RSI 特性分析模块（独立工具）

## 七、风险提示与边界条件

### 7.1 RSI 的固有局限

1. **钝化问题**：在单边强趋势中，RSI 会长期停留在超买/超卖区
   - 牛市中 RSI > 70 可能持续数月
   - 单纯"超买就卖"会在牛市中错过大量涨幅
2. **滞后性**：RSI 是动量指标，对突发事件的反应慢
3. **背离可假**：背离后价格可能继续延续原趋势（"假背离"）
4. **极值不等于反转**：RSI = 85 不代表立即反转，可能继续涨

### 7.2 在 A 股市场的特殊考虑

1. **T+1 交易**：当日买入不能当日卖出，无法做日内交易
2. **涨跌停板**：极端情况下无法成交
3. **政策市**：突发政策可能导致 RSI 信号失效
4. **红利低波的 ETF 跟踪误差**：H20269 是指数，实盘用 ETF（512890/515450）

### 7.3 过拟合风险

**最大风险**：根据历史数据过度优化 RSI 阈值
- 例如：发现"RSI12 = 76.5"是历史最佳卖出点 → 实盘可能完全不工作
- **对策**：
  1. 用 walk-forward 分析（在样本外验证）
  2. 阈值取整（如 75、80，而不是 78.5）
  3. 多起始日稳健性测试（参考 MA250 策略的方法论）

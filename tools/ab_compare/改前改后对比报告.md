# 代码修复前后数据对比报告

> **本文件由脚本生成，可完整复现。** 生成链路：
> `build_legacy.py`（反向补丁重建改前源码）→ `run_ab.py`（双版本各跑一遍）
> → `make_report.py`（本文件）。所有数字来自 `result_*.json`，未经任何手工填写。

## 0. 方法论：为什么这份对比可信

做「改前 vs 改后」对比，最容易出的问题是**改前的数字是编的**（手算、或从旧文档抄）。
本次对比刻意规避：

| 设计 | 目的 |
|------|------|
| 反向补丁重建改前源码，而非引用磁盘旧文件 | 磁盘 `output/` 里旧报告时间戳为 7/24，早于本次会话，中间可能还有其他改动，不是干净对照组 |
| 每处反向替换必须**精确命中 1 次**，否则脚本 `sys.exit(1)` | 保证重建出的 legacy 忠实对应改前代码，而不是手写的近似品 |
| 两版本在**独立子进程**中运行，靠 `sys.path` 选择源码 | 杜绝同进程内 Python 模块缓存交叉污染 |
| 同一份 CSV、同一组参数，唯一变量是源码 | 差异只能来自代码改动 |
| 额外跑 7 个「只启用单个修复」变体 | 把总差异**归因到具体 bug**，而非给出一团无法追溯的总差 |
| 检验各单 bug 增量之和 ≈ 总差（交互项） | 交互项接近 0 才证明隔离正确、归因可信 |

复现命令：

~~~bash
python tools/ab_compare/build_legacy.py
python tools/ab_compare/run_ab.py --version legacy  --out tools/ab_compare/result_legacy.json
python tools/ab_compare/run_ab.py --version current --out tools/ab_compare/result_current.json
for B in A B D E F G H; do
  python tools/ab_compare/build_legacy.py --keep $B --dst var_$B
  AB_SRC=var_$B python tools/ab_compare/run_ab.py --version legacy \
      --out tools/ab_compare/result_only_$B.json
done
python tools/ab_compare/build_legacy.py --keep B,D --dst var_BD   # 交互项验证
AB_SRC=var_BD python tools/ab_compare/run_ab.py --version legacy \
    --out tools/ab_compare/result_only_BD.json
python tools/ab_compare/make_report.py
~~~

## 1. 本次对比覆盖的 7 个修复

| Bug | 一句话 | 改前 | 改后 |
|-----|--------|------|------|
| **A** | 无风险利率单位错配 | 日利率(按365日定义) x 252 x 100 | 直接用年化 `cash_return_rate` |
| **B** | 现金利息漏计日历日 | 每个**交易日**只计 1 天息（一年约 243 天） | 按实际间隔 `(1+d)^elapsed_days`（365 天） |
| **D** | 印花税规则错误 | 买入也征；ETF 也征 | 仅卖出征；ETF/LOF 自动免征 |
| **E** | 阶段收益率公式 | 「累计收益率」末值−首值（策略/基准分母不同且各被放大） | 各段以**前一交易日**为基点，策略与基准同口径 |
| **F** | 阶段划分静默漏天 | 首/末段写死日期，数据边界外的交易日被丢弃 | 首末段敞开(`None`) + **覆盖率断言**硬失败 |
| **G** | 索提诺分母口径 | `std(负收益)`（相对负收益自身均值，只除下跌天数） | `sqrt(mean(min(r,0)^2))`（相对 0，除全部天数） |
| **H** | 年化交易日数硬编码 | 固定 252 | 由数据实测 `len(df)/日历年数` |

并新增：**同仓位静态混合基准**（w 投指数 + (1−w) 投现金，每日再平衡，w = 策略平均仓位），
以及**成本披露**（实际佣金率、触发最低佣金笔数、印花税免征标记）。

读法：

- **累计收益率**只被 B 和 D 改动（B +3.71pp 补回周末利息、D +0.73pp 退回错征的买入印花税）——

- **夏普**下降 0.034，来自 A(−0.028) 与 H(−0.015) 两个口径纠正，被 B/D 的收益增益部分抵消。
  夏普变小不是策略变差，而是**改前把无风险利率算小了、年化天数用大了，虚高了夏普**。
- **索提诺**上升 0.112，主导项是 G(+0.161)。改前的 `std(负收益)` 口径**低估了下行波动**，
  反而**压低**了索提诺；纠正后升高。即 G 此前是**对策略不利**的错误，修复后表现变好，不是粉饰。

## 6. 新增：同仓位静态混合基准（本次最重要的发现）

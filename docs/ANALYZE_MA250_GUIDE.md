# 红利低波价格走势分析程序

## 功能说明

本程序用于分析标的与250日均线（年线）的关系，包括：

1. **交互式HTML图表**（🆕 2026-08-05 升级：RSI 子图 + 5 重交互改进）
   - **上子图（65%）**：收盘价 + 250日均线 + 跌破年线区间阴影
   - **下子图（35%）**：🆕 RSI 6/12/24 三周期曲线 + 70/30 超买超卖辅助线
   - 鼠标悬停联动显示 5 个数值（价格 / MA250 / RSI6 / RSI12 / RSI24）
   - 🆕 底部 rangeslider：拖两个手柄精确选择时间范围
   - 🆕 细化时间范围按钮：1周 / 1月 / 3月 / 6月 / 1年 / 3年 / 5年 / 全部
   - 🆕 spike 十字线：跨子图精确定位日期
   - 🆕 hoverdistance=8：吸附 8 像素内最近点，减少抖动
   - 滚轮缩放、拖拽框选、双击恢复、图例切换
   - 单一HTML格式，便于分享和查看

2. **价格走势 vs 250日均线图表**
   - 绘制标的收盘价走势（深蓝色）和250日均线（红色）
   - 用半透明灰色标注跌破年线到重回年线的时间区间
   - 交互式HTML格式输出

3. **年线乖离率图表**
   - 绘制价格偏离250日均线的百分比
   - 高于年线区域填充绿色，低于年线区域填充红色
   - 交互式HTML格式输出

4. **跌破年线持续交易日长度柱状图**
   - 用柱状图展示每次跌破年线后持续在年线以下的交易日数
   - 每个柱子标注具体的持续天数
   - 横轴显示跌破年线的日期
   - 浅红色柱子：已完成的跌破区间（已重回年线）
   - 金黄色柱子：未完成的跌破区间（截至数据日期仍在年线以下，数值后带*标记）
   - 交互式HTML格式输出

5. **跌破年线买入收益率统计**
   - 统计历次跌破年线后买入的60日和120日收益率
   - 计算平均收益率和标准差
   - 排除最近一次无法计算收益率的情况

## 数据范围

- **H20269 红利低波全收益指数**（含分红复投）
- **时间范围**：2006-01-04 ~ 2026-08-04（5001 条原始数据，4752 条 MA250 后有效）
- **数据跨度**：约 20.6 年
- **重要提醒**：2005-2013 段的 H20269 数据是指数公司基于"编制方案一致"原则的**回算值**，当时并无真实 ETF 可买（512890 成立于 2018），用于策略研究合理，但实盘可行性论证只能用 2018 年后的数据。

## 使用方法

### 方法1：从 Excel 重新生成 CSV（数据更新流程）

当从中证下载了新的 `H30269perf.xlsx` 后：

```bash
# 1. 把新文件放到 data/ 目录
# 2. 运行转换脚本
python scripts/convert_excel_to_csv.py
# 输出：data/H20269历史数据.csv（自动筛选 H20269，过滤 H30269）
```

### 方法2：直接运行画图脚本（推荐）

1. 确保已安装必要的Python库：
   ```bash
   pip install pandas numpy matplotlib plotly openpyxl
   ```

2. 将一个或多个CSV数据文件放在 `data/` 目录下

3. 运行脚本：
   ```bash
   python core/analyze_ma250.py
   ```

4. 按照提示选择要分析的CSV文件（输入文件编号，默认选择第1个）

5. 查看结果：
   - **交互式图表**：`output/analysis/` 文件夹中的HTML文件
   - **统计结果**：`output/analysis/{标的名称}_收益率统计.txt`

### 方法3：作为模块使用

如果要在其他Python脚本中使用：

```python
from analyze_ma250 import MA250Analyzer

# 创建分析器实例
analyzer = MA250Analyzer('data/H20269历史数据.csv')

# 运行完整分析
analyzer.run_analysis(output_dir='output/analysis')
```

### 方法4：分析多个标的

如果要分析多个标的的数据：

1. 准备CSV格式数据文件，包含以下字段（中文列名）：
   - 日期
   - 收盘
   - 开盘
   - 高
   - 低
   - 交易量
   - 涨跌幅

2. 将所有CSV文件放在 `data/` 目录下

3. 运行脚本，每次选择不同的文件进行分析

### 解决"长周期下难以精确选中某一天"的设计思路

数据点 4700+ 条时，相邻点像素距离 < 1，鼠标横向移动 1px 可能跨过 3-5 个数据点，导致 tooltip 飘忽不定。

**5 重组合改进**：
1. **底部 rangeslider**：拖两个手柄缩到日级分辨率
2. **细化按钮**：1周按钮直接缩到最近 7 天
3. **hoverdistance=8**：让 hover 更"粘"
4. **spike 十字线**：跨子图垂直线辅助定位
5. **dragmode='zoom'**：明确启用框选缩放

## RSI 指标说明（🆕 2026-08-05 加入）

### 计算方法
- **算法**：Wilder 平滑法（EMA with α=1/N），行业标准
- **周期**：6/12/24（与同花顺/通达信/东方财富等券商软件一致）
- **三层防护**避免 0/100 极端值：
  1. Wilder 平滑本身减少极值出现频率
  2. avg_gain/avg_loss 双侧 clip(lower=1e-6)
  3. 最终 RSI 硬裁剪到 [0.01, 99.99]

### H20269 历史 RSI 统计（2006-2026，4752 条数据）

| 周期 | 范围 | 均值 | >80 占比 | <20 占比 |
|------|------|------|---------|---------|
| RSI6 | [3.82, 99.99] | 53.60 | 8.65% | 3.37% |
| RSI12 | [13.24, 91.32] | 53.16 | 2.26% | 0.19% |
| RSI24 | [25.44, 83.43] | 52.86 | 0.15% | 0% |

### 关键发现
- 传统 70/30 阈值在 H20269 上过于宽松（触发太频繁）
- RSI 均值略偏多（53.6），反映红利低波"长期慢牛"特性
- 底部 RSI 极值极罕见（RSI12 < 20 仅 9 次），出现即历史大底信号

## 技术说明

### 跌破年线定义
- 前一日收盘价 > 250日均线，且当日收盘价 ≤ 250日均线

### 收益率计算
- 买入时机：第一次跌破年线当天收盘买入
- 60日收益率 = (买入日后第60日收盘价 - 买入日收盘价) / 买入日收盘价 × 100%
- 120日收益率 = (买入日后第120日收盘价 - 买入日收盘价) / 买入日收盘价 × 100%

### RSI 计算
- Wilder 平滑法（EMA with α=1/N）
- 周期：6/12/24（券商标准）
- 三层防护避免 0/100 极端值

### 数据更新
程序设计为可复用，当中证下载新的 H30269perf.xlsx 后：
1. 替换 `data/H30269perf.xlsx`
2. 运行 `python scripts/convert_excel_to_csv.py`
3. 运行 `python core/analyze_ma250.py` 即可得到最新分析结果

## 注意事项

1. CSV文件必须包含至少250条记录才能计算250日均线
2. 确保CSV文件格式正确，日期列可解析
3. 程序会自动排除最近一次跌破但未到120日无法计算收益率的情况
4. 🆕 H20269 在 2005-2013 段是回算数据（无真实 ETF），用于策略研究合理但实盘可行性论证只能用 2018 年后数据

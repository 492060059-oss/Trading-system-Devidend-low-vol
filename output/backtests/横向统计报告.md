# 横向统计报告：21 组回测全量指标 + 分阶段归因

**生成脚本**：`scripts/build_cross_group_report.py`　**组数**：21（H20269 16 + 512890 5）　**阶段行数**：108

> **两个基准的分工（读表前必读）**
>
> - `满仓指数` = 100% 仓位持有指数。策略平均仓位只有 w%，两者**风险暴露不对等**，
>   差额里混了"没满仓"带来的现金拖累与回撤削减。
> - `同仓位混合` = w% 指数 + (1−w%) 现金、每日再平衡。与策略**暴露对等**。
>
> ```
> 策略 − 满仓指数  = 择时贡献 + 现金拖累
> 策略 − 同仓位混合 = 择时贡献        ← 这才是策略的真实增加值
> ```
>
> 回撤同理：`回撤差vs满仓` 含仓位效应，`回撤差vs混合` 才是择时对回撤的净影响。

> **阶段判定口径**
>
> - 超额绝对值 < 0.01 pp 记 **持平**（不计入跑赢也不计入跑输）。全样本 4 例，均为满仓持有、与指数完美跟踪所致。
> - 交易日 < 20 的阶段记 **冷启动残片**：该组起始日恰落在阶段末尾，仓位尚在 0~3%
>   建仓期，跟不上指数属机制必然而非策略判断。全样本 5 例，表中以 `※` 标注，
>   **照常列出但不计入胜率**。

# 滚动仓位策略设计文档

## 最后更新时间
2026-07-24（含深度定投、快照启动、小额资金全仓买入处理、🆕 交易成本建模）

## 策略概述

### 设计理念
从简单的框架开始，使用10万元滚动仓位作为demo，验证跌破年线买入+乖离率卖出策略的有效性。

### 核心思想
- **买入信号**：跌破年线触发定投
- **卖出信号**：严重超过年线时分批卖出
- **资金管理**：空仓资金享受年化收益，持仓资金跟随标的走势
- **优先级**：卖出信号优先级高于买入信号

### 参数说明

#### 1. 定投交易日数（n）
- **定义**：跌破年线后，将剩余资金平均分成n份，在n个交易日内逐步买入
- **执行规则**：
  - 只在交易日执行定投
  - 每个交易日定投金额 = 剩余资金 / 剩余定投天数
  - 如果触发卖出信号，立即暂停定投

#### 2. 第一卖出阈值（a%）
- **定义**：乖离率超过年线a%时，卖出当前持仓的50%
- **触发条件**：`乖离率 = (收盘价 - 年线) / 年线 × 100% > a%`
- **重要规则**：
  - 每个周期只触发一次
  - 如果卖出后乖离率跌回a%以下又重新超过a%，不再重复卖出
  - 只有继续上涨到b%才会触发第二笔卖出

#### 3. 第二卖出阈值（b%）
- **定义**：乖离率超过年线b%时，卖出当前持仓的剩余50%
- **触发条件**：`乖离率 > b%`
- **前提条件**：必须先触发过a%的卖出
- **重要规则**：
  - 如果没有触发过a%，即使超过b%也不卖出
  - 每个周期只触发一次
  - 如果先触发b%（极少见，直接暴涨），按b%卖出全部持仓

#### 4. 空仓年化收益率（c%）
- **定义**：未买入的资金享受的年化收益率
- **计算方式**：每日复利计算
  - 每日收益率 = (1 + c%)^(1/365) - 1
  - 每日利息 = 剩余资金 × 每日收益率
- **说明**：模拟货币基金或银行理财收益

#### 5. 🆕 回测起止日期（start_date / end_date）
- **定义**：策略回测的时间范围
- **使用方式**：
  - `data_calculator` 仍计算全量数据的 MA250/乖离率
  - `rolling_position_backtest` 按起止日期过滤回测数据
  - 确保起始日的 MA250 数据已计算完成
- **特殊处理**：
  - 若 `start_date=None`，使用数据首日（约 2014-07-23）
  - 若 `end_date=None`，使用数据末日
  - 起始日的状态由"快照启动"规则决定（见下文）

#### 6. 🆕 深度定投档位（dca_tiers）
- **定义**：根据当日乖离率深度调整定投金额倍数
- **默认配置**（三档加倍）：

| 乖离率区间 | 定投倍数 | 说明 |
|-----------|---------|------|
| divergence > -4% | 1× | 含年线上方（仍 1×） |
| -8% < divergence ≤ -4% | 2× | 中度下跌加速建仓 |
| divergence ≤ -8% | 3×（封顶） | 深度下跌密集建仓 |

- **设计要点**：
  - 倍数基于**起始定投时的现金 / n** 计算固定基础金额（不重分配）
  - 允许在 n 天内提前打满资金（深度区连续定投时）
  - 若当日计划投入 > 剩余现金，按剩余现金实际投入（兜底）
- **可扩展性**：
  - `dca_tiers` 支持自定义档位（增加细分区间）
  - 支持修改倍数（如 1.5×、2.5×）
  - 支持回退到原策略（传入空列表 `[]` 即全 1×）

## 策略规则详解

### 买入策略

#### 🆕 快照启动规则（起始日特殊处理）

**场景**：当回测起始日价格已经在年线下方（close ≤ MA250）时，原策略的"前一日 > MA250 且当日 ≤ MA250"信号无法触发，会导致策略无法开始定投。

**快照启动规则**：
- 在回测首日（i=0）检查 `close vs MA250` 关系
- 若 `close ≤ MA250`：直接 `is_investing=True`、`remaining_days=n`，并计算 `base_daily_amount = cash / n`，当日按深度定投规则执行
- 若 `close > MA250`：保持空仓，等待首次"跌破年线"信号

**约束**：
- 仅在回测首日（i=0）执行快照判断
- 假定起始时无任何底仓（100% 空仓）
- 有底仓的情况暂不支持（列入 PROGRESS.md 待办事项）

#### 触发条件
- **信号**：收盘价跌破250日年线
- **定义**：前一日收盘价 > 年线，且当日收盘价 ≤ 年线

#### 执行规则
1. **首次触发跌破年线**：
   - 将当前全部现金分成n份
   - **计算固定基础金额**：`base_daily_amount = cash / n`
   - 计划在接下来的n个交易日内每日定投一份（实际投入按深度定投规则加倍）
   - 设置标记：`is_investing = True`，`remaining_days = n`

2. **每日执行**（🆕 含深度定投）：
   - 检查是否为交易日（是交易日才执行）
   - **计算当日倍数**：根据当日乖离率查询 `dca_tiers`
   - **计划投入**：`planned_amount = base_daily_amount × multiplier`
   - **实际投入**：`invest_amount = min(planned_amount, 剩余现金)` ← 兜底
   - 使用当日收盘价买入
   - 剩余定投天数 -= 1（**注意：base_daily_amount 不重分配**）
   - 若剩余现金 ≤ 0，强制结束定投

3. **⚠️ 重要：定投不重置原则**：
   - **一次跌破年线触发定投后，定投天数是固定的**
   - **即使在定投过程中价格涨回年线以上又重新跌破年线，也不能重置为n天定投**
   - **base_daily_amount 在整个定投周期内保持不变**（不随消耗重分配）
   - **必须继续之前的定投计划，直到以下任一情况发生：**
     - 定投全部完成（remaining_days = 0）
     - 触发卖出信号（停止定投）
     - 剩余现金耗尽（提前结束）
   - **只有在触发卖出后，完成了一个完整周期，下次跌破年线时才能重新开始n天定投**

   **举例说明**：
   - 第1天跌破年线，开始40天定投，剩余资金10万，base_daily_amount = 2,500
   - 第10天涨回年线以上（继续定投，剩余30天，按1×投入2,500）
   - 第20天重新跌破年线（**不重置**，继续定投，剩余20天）
   - 第30天再次跌破年线（**不重置**，继续定投，剩余10天）
   - 第40天定投完成，等待卖出信号
   - 如果第50天触发卖出，下次跌破年线时才重新开始40天定投（重新计算 base_daily_amount）

4. **触发卖出后的处理**：
   - **如果触发卖出信号**：立即暂停定投，保留剩余现金
   - **清空所有买入状态标记**：`is_investing = False`，`remaining_days = 0`
   - **下次跌破年线时**：重新开始n天定投（重新计算 base_daily_amount = 当前剩余现金 / n）

5. **继续定投条件**：
   - 即使价格回升到年线以上，只要不触发卖出信号，继续定投
   - 定投过程中乖离率在0~a%之间波动不影响定投
   - **🆕 即使价格涨回年线上方（乖离率>0），仍按 1× 继续定投**（直到 remaining_days=0）

#### 🆕 深度定投规则（核心新增）

**触发时机**：每日执行定投时（即 `is_investing=True 且 当日不触发卖出`）

**倍数判断逻辑**：
```python
def get_dca_multiplier(divergence, dca_tiers):
    """dca_tiers 按 threshold 从小到大排列，命中第一个 divergence <= threshold 的档位"""
    for threshold, multiplier in dca_tiers:
        if divergence <= threshold:
            return multiplier
    return 1.0  # 默认1倍
```

**默认 dca_tiers = [(-8.0, 3.0), (-4.0, 2.0)]** 的实际效果：

| 当日乖离率 | 命中条件 | 倍数 |
|-----------|---------|------|
| divergence ≤ -8% | 第一档 (-8.0, 3.0) | 3× |
| -8% < divergence ≤ -4% | 第二档 (-4.0, 2.0) | 2× |
| -4% < divergence（含年线上方） | 无命中 | 1× |

**资金计算规则**：

1. **基础金额固定**（关键设计）：
   - 在"开始定投"或"强制重置+开始定投"触发时**计算一次**
   - `base_daily_amount = 当时剩余现金 / n`
   - 整个定投周期内 `base_daily_amount` **不变**

2. **实际投入**：
   - `planned_amount = base_daily_amount × multiplier`
   - `actual_invest = min(planned_amount, 当前剩余现金)` ← 兜底逻辑

3. **资金管理特点**：
   - 允许在 n 天内**提前打满资金**（深度区连续定投时）
   - 不做"重分配"（不同于原代码的 `cash / remaining_days` 滚动更新）
   - 资金耗尽时提前结束定投（设置 `is_investing=False`, `remaining_days=0`）

**示例**（假设起始定投时现金 = 100,000 元，n=40，base_daily_amount = 2,500）：

| 日 | 乖离率 | 倍数 | 计划投入 | 实际投入 | 剩余现金 | 剩余天数 |
|----|-------|------|---------|---------|---------|---------|
| 1 | -2% | 1× | 2,500 | 2,500 | 97,500 | 39 |
| 2 | -5% | 2× | 5,000 | 5,000 | 92,500 | 38 |
| 3 | -10% | 3× | 7,500 | 7,500 | 85,000 | 37 |
| 4 | +3%（涨回年线上方，未触发止盈） | 1× | 2,500 | 2,500 | 82,500 | 36 |
| ... | ... | ... | ... | ... | ... | ... |
| 35 | 剩余现金仅 2,000 | 3× | 7,500 | **2,000**（兜底） | 0 | 34 |

**重要边界**：
- 即使价格涨回年线上方（乖离率 > 0），只要未触发止盈且 remaining_days > 0，仍按 1× 继续定投
- **强制重置开启新一轮定投时**：重新计算 `base_daily_amount = 当前剩余现金 / n`，新定投也按深度加倍规则
- **快照启动**（起始日 close ≤ MA250）：同样计算 `base_daily_amount = cash / n`，首日即按深度加倍
- **可扩展性**：传入 `dca_tiers=[]` 即回退到原策略（全 1× 定投）

#### 触发卖出后的处理

### 卖出策略

#### ⚠️ 重要：卖出触发周期性原则

**核心定义**：
- a%和b%的卖出阈值是相对于**一个完整的交易周期**
- **一个完整周期** = 跌破年线 → n天定投 → 触发a%卖出50%（周期未结束，`triggered_a=True`保持）→ 触发b%清仓（周期结束）
- ⚠️ **重要**：触发a%卖出50%**不算周期结束**，只有b%清仓（或触发a%后再跌破年线强制重置）才算周期结束

**周期边界**：
- **周期开始**：跌破年线，开始定投（包括首次跌破年线、b%清仓后的下次跌破年线、以及"触发a%后再次跌破年线"的强制重置）
- **周期中间态**：触发a%卖出50%后，`triggered_a=True`保持，持仓剩余50%，停止定投，**周期仍然继续**
- **周期结束**（仅以下两种情况）：
  1. **b%清仓**：先触发a%后再触发b%，或直接跳过a%到b%一次性清仓
  2. **触发a%后再次跌破年线**：强制重置`triggered_a=False`，**立即开启新一轮40天定投**（不复用旧的剩余天数）
- **新周期**：周期结束后，下次跌破年线（或同日触发"再跌破年线重置"）开始新一轮定投

**关键规则**：
1. **在一个周期内**：
   - a%卖出最多触发一次（`triggered_a=True`后保持，直到周期结束才重置）
   - b%卖出最多触发一次（且必须先触发过a%，或直接跳过a%一次性清仓）
   - **a%卖出后，本周期不再因乖离率涨跌而调整仓位**（除非触发b%清仓 或 再次跌破年线重置）

2. **周期结束后重置**：
   - **b%清仓后**：所有状态标记（`is_investing`、`remaining_days`、`triggered_a`、`triggered_b`）全部重置为初始值，等待下次跌破年线
   - **触发a%后再次跌破年线**：`triggered_a`重置为False，`is_investing=True`、`remaining_days=n`，**立即开启新一轮n天定投**（不复用旧的剩余天数）

3. **跨周期场景示例**：
   - 第1周期：跌破年线 → 定投 → 乖离率达16%（超过a=15%） → 卖出50%，`triggered_a=True`，停止定投，**周期继续**
   - 价格回落，**未跌破年线**：仓位保持不动，等待b%或再次跌破年线
   - 价格继续回落，**跌破年线**：重置`triggered_a=False`，立即开启新一轮n天定投（旧周期结束，新周期开始）
   - 第2周期：新一轮定投 → 乖离率再次达16% → 可以再次触发a%卖出50%（基于当前所有持仓）

**举例说明周期性**：
```
场景A：触发a%后顺利走到b%清仓
  Day 1:   跌破年线，开始40天定投
  Day 20:  乖离率=16%（>a=15%），卖出50%，triggered_a=True，停止定投（周期未结束）
  Day 25:  价格回落，乖离率=12%（<a%，仍>0），仓位不动，triggered_a保持True
  Day 28:  价格反弹，乖离率=16%（再次>a%），仓位仍不动（周期内a%只触发一次）
  Day 35:  价格大涨，乖离率=18%（>b=17.5%），清仓卖出剩余50%，周期结束
  → 所有状态重置为False/0

场景B：跳过a%直接到b%（一次性清仓）
  Day 50:  跌破年线，开始40天定投
  Day 70:  乖离率=18%（一天内从14%直接跳到18%，跳过a%），一次性清仓，周期结束
  → 所有状态重置为False/0

场景C：触发a%后再跌破年线（强制重置开启新周期）
  Day 1:   跌破年线，开始40天定投
  Day 20:  乖离率=16%（>a%），卖出50%，triggered_a=True，停止定投
  Day 35:  价格大幅回落，跌破年线 → triggered_a重置为False，
           立即开始新一轮40天定投（旧周期结束，新周期开始）
  Day 75:  （新一轮定投中）继续定投
  Day 90:  乖离率=16%（>a%），再次触发a%卖出50%（基于当前持仓），triggered_a=True
  Day 100: 乖离率=18%（>b%），清仓，周期结束
```

#### 触发条件（按优先级从高到低判断，每日只走一个分支）

⚠️ **检查顺序极为重要**：必须先检查"特殊情况（跳过a%到b%）"，再检查"第一级卖出"，最后检查"第二级卖出"。

1. **特殊情况（最高优先级）**：`triggered_a==False 且 triggered_b==False 且 乖离率 > b%`（即未触发过a%而乖离率已超过b%，跳过a%）
2. **第一级卖出**：`triggered_a==False 且 乖离率 > a% 且 持仓>0`
3. **第二级卖出**：`triggered_a==True 且 triggered_b==False 且 乖离率 > b% 且 持仓>0`

#### 执行规则

##### 特殊情况：跳过a%直接到b%（最高优先级，需最先检查）
1. **触发时机**：本周期内未触发过a%（`triggered_a==False`），但当日乖离率已经 > b%
   - 典型场景：前一日乖离率=14%（<a%），当日暴涨到18%（>b%），一天内跨越a%和b%
2. **卖出操作**：**一次性清仓全部持仓**（不是先卖50%再卖50%）
3. **状态变化**：
   - `triggered_a = True`（瞬时标记，仅用于流程统一）
   - `triggered_b = True`
   - 立即重置所有状态（见"卖出后处理"）
4. **周期结束**：是，清仓后立即重置所有状态

##### 第一级卖出（a%触发）
1. **触发时机**：`triggered_a==False 且 乖离率 > a% 且 持仓>0`
2. **卖出操作**：卖出**当前持仓的50%**
3. **状态变化**：
   - ✅ `triggered_a = True`（**关键修复**：必须设为True，不是False！）
   - ✅ `is_investing = False`（立即停止定投）
   - ✅ `remaining_days = 0`（清空定投天数）
   - ❌ **不重置** `triggered_b`（保持原值，本周期内始终为False）
   - ❌ **不算周期结束**，仓位继续持有剩余50%
4. **后续规则**（`triggered_a=True`期间的行为）：
   - 若乖离率在 (0%, a%) 区间波动：仓位不动
   - 若乖离率跌回a%以下后再次涨回a%以上：**仍不卖出**（周期内a%只触发一次）
   - 若乖离率涨到 > b%：触发第二级卖出，清仓
   - 若价格跌破年线：触发"周期强制重置"，开始新一轮n天定投（详见下方"triggered_a=True后的处理"）

##### 第二级卖出（b%触发）
1. **触发时机**：`triggered_a==True 且 triggered_b==False 且 乖离率 > b% 且 持仓>0`
2. **卖出操作**：卖出**当前持仓的剩余100%**（清仓）
3. **状态变化**：
   - `triggered_b = True`（瞬时标记）
   - 立即重置所有状态（见"卖出后处理"）
4. **周期结束**：是，清仓后立即重置所有状态

#### 🆕 triggered_a=True 后的处理逻辑（关键新增章节）

当第一级卖出触发后（`triggered_a=True`），系统进入"等待状态"，根据后续价格走势采取不同行动：

| 后续情况 | 乖离率 | 价格与年线关系 | 操作 | 状态变化 |
|---------|-------|---------------|------|---------|
| 情况1 | 跌回 <a% | 仍 > 年线（乖离率>0） | **仓位不动** | 保持`triggered_a=True` |
| 情况2 | 再次涨回 >a%（但 ≤b%） | 仍 > 年线 | **仓位不动**（周期内不重复触发a%） | 保持`triggered_a=True` |
| 情况3 | 涨到 >b% | 任意 | **清仓**（触发第二级卖出） | 周期结束，全部重置 |
| 情况4 | 任意 | **跌破年线**（前一日>MA250，当日≤MA250） | **强制周期重置，立即开启新一轮n天定投** | `triggered_a=False`、`is_investing=True`、`remaining_days=n` |

**情况4的详细说明（重要）**：
- 触发a%卖出后，如果价格大幅回落并**新发生一次"跌破年线事件"**（前一日>MA250，当日≤MA250），则：
  1. `triggered_a` 重置为 False（上周期结束）
  2. **立即开始新一轮n天定投**：`is_investing=True`、`remaining_days=n`、`daily_invest_amount = 当前剩余现金 / n`
  3. 新一轮周期内，若乖离率再次涨到 >a%，仍按"第一级卖出"规则卖出当前持仓的50%（基于此时点的全部持仓）
  4. 新一轮定投金额基于**当前剩余现金**（上一轮定投已用的资金不复位）
- ⚠️ 注意：这里的"跌破年线"必须是**新发生的跌破事件**（前一日>MA250，当日≤MA250）。如果价格已经在年线以下持续了多日，不算"新跌破"，不触发重置。

#### 卖出后处理（周期结束）

周期结束有两种路径，统一处理如下：

**路径A：b%清仓（包括先a%后b%、以及跳过a%直接b%）**
- 卖出获得现金继续享受c%年化收益
- **清空所有状态标记**：
  - `is_investing = False`
  - `remaining_days = 0`
  - `daily_invest_amount = 0`
  - `triggered_a = False`
  - `triggered_b = False`
- `shares = 0`（已清仓）
- **等待下次"跌破年线"信号，开始新的交易周期**

**路径B：触发a%后再跌破年线（强制重置）**
- 保留剩余持仓（不清仓）
- `triggered_a = False`
- `is_investing = True`，`remaining_days = n`，`daily_invest_amount = 当前剩余现金 / n`
- **立即开始新一轮n天定投**（从当日开始执行第一笔定投）

### 优先级规则

#### 卖出优先级 > 买入优先级
1. **场景描述**：定投过程中触发卖出信号（a% 或 b%）
2. **执行顺序**：
   - 立即停止定投（`is_investing=False`、`remaining_days=0`）
   - 执行卖出操作
   - 保留剩余现金
3. **后续处理**：
   - 若是a%卖出：`triggered_a=True`，仓位保留50%，进入"等待状态"（见上方"triggered_a=True后的处理"）
   - 若是b%卖出（清仓）：周期结束，等待下次跌破年线
   - 在`triggered_a=True`期间，即使价格回到a%以下也不重新买入；必须等到周期结束（b%清仓 或 再次跌破年线重置）才能开启新一轮定投

## 资金计算模型

### 初始设置
- **总资金**：100万元（本demo使用10万元）
- **初始状态**：100%现金，0%持仓
- **起始日期**：H20269第一笔年线数据出现日（约2014年7月）

### 每日资金更新

#### 1. 空仓资金利息计算
```
每日收益率 = (1 + c%)^(1/365) - 1
当日利息 = 空仓资金 × 每日收益率
空仓资金 += 当日利息
```

#### 2. 持仓市值更新
```
持仓市值 = 持有份额 × 当日收盘价
总资产 = 空仓资金 + 持仓市值
```

#### 3. 买入操作
```
买入金额 = min(计划定投金额, 空仓资金)
买入份额 = 买入金额 / 当日收盘价
空仓资金 -= 买入金额
持有份额 += 买入份额
```

#### 4. 卖出操作
```
卖出份额 = 当前持有份额 × 卖出比例
卖出金额 = 卖出份额 × 当日收盘价
持有份额 -= 卖出份额
空仓资金 += 卖出金额
```

### 收益率计算

#### 策略收益率
```
策略日收益率 = (当日总资产 - 前一日总资产) / 前一日总资产
累计收益率 = (当前总资产 - 初始资金) / 初始资金
```

#### 标的收益率（H20269基准）
```
标的日收益率 = (当日收盘价 - 前一日收盘价) / 前一日收盘价
标的累计收益率 = (当前收盘价 - 起始日收盘价) / 起始日收盘价
```

### 🆕 深度定投倍数查询函数
```python
def get_dca_multiplier(divergence, dca_tiers):
    """
    dca_tiers 按 threshold 从小到大排列
    命中第一个 divergence <= threshold 的档位
    """
    for threshold, multiplier in dca_tiers:
        if divergence <= threshold:
            return multiplier
    return 1.0  # 默认1倍

# 默认配置示例
dca_tiers = [(-8.0, 3.0), (-4.0, 2.0)]  # ≤-8%: 3×, ≤-4%: 2×, 其他: 1×
```

### 每日循环逻辑
```python
# ============ 0. 🆕 快照启动（仅首日 i=0）============
if i == 0:
    if current_close <= current_ma250:
        # 起始价在年线下方，直接开始定投
        is_investing = True
        remaining_days = n
        base_daily_amount = cash / n

for each trading day:
    1. 更新当日收盘价、年线、乖离率
    2. 计算空仓资金利息
    3. 更新持仓市值和总资产

    4. 检查卖出信号（按优先级从高到低，每日只走一个分支）
       sell_triggered = False

       # 4a. 特殊情况：跳过a%直接到b%（最高优先级）
       if (not triggered_a and not triggered_b
           and current_divergence > b and shares > 0):
           清仓全部持仓
           # 周期结束 → 全部重置
           is_investing = False; remaining_days = 0; base_daily_amount = 0
           triggered_a = False; triggered_b = False
           sell_triggered = True

       # 4b. 第一级卖出：a%触发
       elif (not triggered_a and current_divergence > a and shares > 0):
           卖出当前持仓的50%
           triggered_a = True              # ✅ 关键：设为True
           is_investing = False             # 立即停止定投
           remaining_days = 0
           base_daily_amount = 0
           # ⚠️ 周期未结束，不重置 triggered_b
           sell_triggered = True

       # 4c. 第二级卖出：b%触发（必须先触发过a%）
       elif (triggered_a and not triggered_b
             and current_divergence > b and shares > 0):
           清仓全部持仓
           # 周期结束 → 全部重置
           is_investing = False; remaining_days = 0; base_daily_amount = 0
           triggered_a = False; triggered_b = False
           sell_triggered = True

    5. 检查"triggered_a=True后再跌破年线"的强制重置
       if (not sell_triggered and triggered_a
           and prev_close > prev_ma250 and current_close <= current_ma250):
           # 周期强制结束，开启新一轮定投
           triggered_a = False
           is_investing = True
           remaining_days = n
           base_daily_amount = cash / n  # 🆕 重新计算固定基础金额
           # 注意：不设 sell_triggered=True，让步骤7的定投分支可以执行

    6. 检查常规买入信号
       if (not sell_triggered and not triggered_a
           and prev_close > prev_ma250 and current_close <= current_ma250):
           if not is_investing:
               # 开始新的n天定投
               is_investing = True
               remaining_days = n
               base_daily_amount = cash / n  # 🆕 计算固定基础金额
           # else: 正在定投中，不重置（定投不重置原则）

    7. 🆕 执行定投（含深度加倍）
       if (is_investing and not sell_triggered and remaining_days > 0):
           if cash <= 0:
               # 资金耗尽，提前结束定投
               is_investing = False
               remaining_days = 0
               base_daily_amount = 0
           else:
               # 计算当日倍数
               multiplier = get_dca_multiplier(current_divergence, dca_tiers)
               planned_amount = base_daily_amount × multiplier
               invest_amount = min(planned_amount, cash)  # 🆕 兜底
               buy_shares = invest_amount / current_price

               shares += buy_shares
               cash -= invest_amount
               remaining_days -= 1
               # ⚠️ 不再重分配 base_daily_amount（关键改动！）

               if remaining_days == 0:
                   is_investing = False
                   base_daily_amount = 0

    8. 记录当日状态
    9. 计算当日收益率
```

   - 不应将10%视为超买信号
   - a%和b%应明显高于10%（如15%、17.5%）

2. **单次触发原则**：
   - a%和b%的卖出在每个周期只触发一次
   - 避免震荡市中频繁交易

3. **卖出优先级**：
   - 一旦触发卖出，立即停止定投
   - 必须等待下次跌破年线才能重新买入

- ✅ **一次跌破年线触发定投后，定投天数固定为n天**
- ✅ **定投过程中即使多次跌破年线，也不重置定投天数**
- ✅ **只有在触发卖出后（或同周期内触发a%后再次跌破年线强制重置），才能重新开始n天定投**

**影响**：避免在同一个建仓周期内多次重复开启定投，确保资金分批建仓的纪律性。

### 修正点2：卖出触发周期性原则（重要：含Bug修复）

**原代码的Bug**：`rolling_position_backtest.py` 旧版本中，触发a%卖出50%后立即把 `triggered_a=False`、`triggered_b=False`，导致：
- 第二天乖离率仍 >a% 时，又触发一次a%卖出50%（连续卖出）
- 历史回测中出现过8天连续卖出，持仓从10.2份降到0.08份（卖出99.2%）
- 同时第二级卖出条件错误地写成 `not triggered_a and not triggered_b`，使得"先a%后b%"的正常流程几乎不可能触发

**修正**：
- ✅ **a%卖出后**：`triggered_a=True`（不是False！），`is_investing=False`，`remaining_days=0`，**周期未结束**
- ✅ **b%卖出（清仓）后**：才是真正的周期结束，重置所有状态
- ✅ **第二级卖出条件**：`triggered_a==True 且 not triggered_b 且 乖离率>b%`（必须先触发过a%）
- ✅ **特殊情况（跳过a%到b%）**：作为最高优先级分支，一次性清仓

### 修正点3：triggered_a=True 后再跌破年线的强制重置（新增）

**新增规则**：触发a%卖出后，如果价格大幅回落并**新发生跌破年线事件**：
- 重置 `triggered_a=False`
- 立即开启新一轮n天定投（不复用旧的剩余天数）
- 新一轮定投金额基于**当前剩余现金**

**影响**：避免a%卖出后仓位长期"卡死"在等待b%的状态，让策略能在震荡市中灵活重新建仓。

### 修正点4：卖出检查顺序（新增）

**检查顺序**（每日只走一个分支）：
1. 特殊情况（跳过a%到b%）→ 一次性清仓
2. 第一级卖出（首次到a%）→ 卖50%
3. 第二级卖出（已触发a%后再到b%）→ 清仓

**影响**：避免"一天内乖离率从14%跳到18%"被误走成第一级卖出（应该走特殊情况一次性清仓）。

### 修正点5：🆕 深度定投机制（2026-07-23 新增）

**新增规则**：定投金额按当日乖离率深度加倍。

**倍数档位**（可通过 `dca_tiers` 参数自定义）：
- `divergence > -4%`：1×（默认，含年线上方）
- `-8% < divergence ≤ -4%`：2×
- `divergence ≤ -8%`：3×（封顶）

**关键设计**：
- 基础金额固定 = 起始定投时的现金 / n（**不重分配**）
- 允许在 n 天内提前打满资金（深度区连续定投时）
- 若剩余现金不足计划投入，按剩余现金实际投入（兜底）
- 价格涨回年线上方仍按 1× 定投（直到 `remaining_days=0` 或触发卖出）
- 强制重置时重新计算 `base_daily_amount = 当前剩余现金 / n`

**影响**：在深度熊市中密集建仓，抓住底部机会，提升长期收益。

**可扩展性**：传入 `dca_tiers=[]` 即回退到原策略（全 1× 定投），方便对比测试。

### 修正点6：🆕 快照启动与任意起止日期（2026-07-23 新增）

**新增规则**：
1. 支持任意 `start_date` / `end_date` 回测
2. 起始日若 `close ≤ MA250`，直接开始定投（不依赖"前一日 > MA250 且当日 ≤ MA250"事件）

**影响**：可以在任意历史时间段验证策略表现，无需从数据首日开始。

**待扩展**：起始时有底仓的情况暂不支持（列入 PROGRESS.md 待办）。

## 🆕 小额资金处理（2026-07-23 新增）

### 问题背景

**致命 Bug**：原策略中，当剩余资金 `cash` 很小（如清仓后浮点残留、空仓利息累积等场景出现 0.07 元、0.001 元甚至更小），策略仍然会按 `base_daily_amount = cash / 40` 分成 40 份定投，导致：

- 实际单次定投金额低至 `2.668e-08` 元（一分钱的 3.75 亿分之一）
- 在 2015-05 起的回测中，420 次定投里有 **174 次（41%）实际金额 < 100 元**
- 实盘中券商最低佣金 5 元/笔，这种小额交易佣金占比高达 13%+，完全不可执行

### 解决方案：三层资金判断

引入两个新参数：

| 参数 | 默认值 | 含义 |
|------|--------|------|
| `lump_sum_threshold` | 2000 元 | cash < 此值时一次性全仓买入（不分 40 份） |
| `noise_threshold` | 1 元 | cash < 此值视为浮点噪声，忽略信号 |

**核心规则**：

| cash 范围 | 处理方式 |
|----------|---------|
| `cash < noise_threshold`（< 1元）| **忽略信号**，不记录任何交易（认为是浮点噪声）|
| `noise_threshold ≤ cash < lump_sum_threshold`（1-2000元）| **一次性全仓买入**，不进入 40 日定投模式 |
| `cash ≥ lump_sum_threshold`（≥ 2000元）| **正常 40 日定投**（原逻辑）|

### 4 处应用位置

小额资金判断在以下 4 处触发：

1. **快照启动**（首日 close ≤ MA250）：
   - cash < 阈值 → 操作记录为 `快照启动+全仓买入`
2. **强制重置**（triggered_a 期间跌破年线）：
   - cash < 阈值 → 操作记录为 `强制重置+全仓买入`
3. **正常开始定投**（首次跌破年线）：
   - cash < 阈值 → 操作记录为 `全仓买入(跌破年线)`
4. **执行定投过程中**（cash 降到阈值以下）：
   - cash < 阈值 → 操作记录为 `定投终止+全仓买入`，提前结束周期

### 操作记录命名约定

| 场景 | 操作名 |
|------|--------|
| 快照启动 + 小资金 | `快照启动+全仓买入` |
| 强制重置 + 小资金 | `强制重置+全仓买入` |
| 跌破年线 + 小资金 | `全仓买入(跌破年线)` |
| 定投中资金不足 | `定投终止+全仓买入` |
| 信号被忽略（噪声）| 不记录交易，仅在每日记录的"备注"中体现 |

### 修复前后对比（2015-05 起回测）

| 指标 | 修复前 | 修复后 | 变化 |
|------|--------|--------|------|
| 总交易次数 | 428 | 264 | -164 次（-38%）|
| 实际金额 < 100 元的定投 | 174 次 | **0 次** | ✅ 完全消除 |
| 累计收益率 | 202.77% | 202.81% | +0.04%（几乎不变）|
| 夏普比率 | 0.71 | 0.71 | 不变 |

### 阈值参数选择依据

- **`lump_sum_threshold = 2000 元`**：
  - 券商最低佣金 5 元/笔对应的最小经济交易金额
  - 佣金占比 ≤ 0.25%（万分之2.5以下才有意义）
  - 涵盖 ETF 最小交易单位（100 股 × 1-5 元/股 = 100-500 元）的 2-4 倍缓冲
- **`noise_threshold = 1 元`**：
  - 浮点数精度残留通常 < 0.1 元
  - 1 元的利息累积需要约 100 天（年化 1.2%），不会误伤正常场景

## 🆕 交易成本建模（2026-07-24 新增）

### 设计目标

让回测更贴近实盘，验证策略在扣除交易摩擦后是否仍跑赢基准。

### 适用范围

✅ **当前已建模**：
- 场内交易佣金（双边收取）
- 印花税（双边收取，按用户简化要求；注：A 股实际仅卖出收取 0.05%）
- 最低佣金 5 元/笔（A 股实盘规则）

❌ **暂未建模**（用户已明确暂不实现）：
- ETF 管理费（年化 1%）
- 滑点
- 基准同步扣成本（基准保持纯价格涨幅）
- 次日开盘成交（仍用当日收盘价）

### 费率参数

| 参数 | 默认值 | 含义 |
|------|--------|------|
| `enable_trading_costs` | True | 是否启用交易成本（False 时完全回退到原逻辑） |
| `commission_rate` | 0.00025（0.025%） | 单边佣金率，买卖均收取 |
| `stamp_duty_rate` | 0.0005（0.05%） | 单边印花税率，买卖均收取 |
| `min_commission` | 5.0 元 | 每笔佣金最低值 |

### 买入成本计算（关键公式）

**语义**：`invest_amount` 是"从 cash 扣的总额"（含费用），需反算实际用于买份额的金额 `gross`。

**情况 1：未触发最低佣金**（`invest_amount × commission_rate ≥ min_commission`，即 `invest_amount ≥ 20000` 元）

```
gross = invest_amount / (1 + commission_rate + stamp_duty_rate)
commission = gross × commission_rate
stamp_duty = gross × stamp_duty_rate
buy_shares = gross / price
```

**情况 2：触发最低佣金**（`invest_amount < 20000` 元）

```
commission = min_commission  # 固定 5 元
gross = (invest_amount - min_commission) / (1 + stamp_duty_rate)
stamp_duty = gross × stamp_duty_rate
buy_shares = gross / price
```

**防御性处理**：若 `invest_amount ≤ min_commission`（极端小额），全部金额作为佣金，gross=0（费用吞噬）。

### 卖出成本计算

**语义**：从毛收入（`sell_shares × price`）扣除费用后入 cash。

```
commission = max(gross × commission_rate, min_commission)
stamp_duty = gross × stamp_duty_rate
net_proceeds = gross - commission - stamp_duty
cash += net_proceeds
```

### 应用位置（6 处）

**4 处买入**：
1. `_execute_lump_sum_buy`（快照启动/强制重置/跌破年线触发的全仓买入）
2. 定投终止 + 全仓买入
3. 正常定投（40 日 DCA 中的每一笔）

**3 处卖出**：
1. 跳过a%直接清仓
2. 第一级卖出 50%
3. 第二级清仓

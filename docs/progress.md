**算术错误**（已验证）：`ROLLING_POSITION_STRATEGY.md:717-719` 称"10%乖离率 = 比前一年涨了10%"。**前提是错的** —— 乖离率是对 250 日**均值**的偏离，不是对 250 日前**价格**的偏离。对趋势 g，稳态乖离 = `g/(1-e^-g) - 1`：

| 趋势 g | 稳态乖离率 |
|--------|-----------|
| 5% | 2.52% |
| **10%** | **5.08%**（不是 10%！） |
| 20% | 10.33% |
| 30% | 15.75% |

### 🐛 0.23. Bug K：无交易日的「操作」列一律误标为"空仓"（2026-08-23）

**发现过程**：在为用户解读 2020-01 组末段（2024-09-24 起 924 行情）时，
日志出现自相矛盾的一行 —— `操作=空仓` 却同时 `持仓份额 9.8 / 闲置资金 0 / 当日 +4.42%`。
"空仓"不可能单日涨 4.42%。追下去发现是标签 bug，不是收益算错。

**根因**（`core/rolling_position_backtest.py:426`）：

```python
daily_record = { ..., '操作': '空仓', '备注': '' }   # ← 字面量当默认值
```

`'空仓'` 被当作 dict 的**默认初始值**，只在当日真的发生交易时才被后续分支覆盖。
于是**所有"持有不动"的日子都被标成"空仓"**，无论实际仓位是 0% 还是 100%。

**规模**：2020-01 组 1596 个交易日里，**1394 天被误标**（真正空仓仅 202 天）。

**影响面**：**纯展示层**。所有收益/回撤/夏普指标都走 `总资产` 字段，
不读 `操作`；下游只有两处 `isin([...])` 过滤**具名交易标签**（`开始定投`/`卖出50%` 等），
不依赖 `空仓`。`audit_checks.py` 的 B 项判定空仓用的是 `持仓市值 <= 1e-9` 而非标签，
所以此前所有数字都是对的 —— 但这一列会严重误导人读交易记录（我自己差点被骗）。

**修法**：`'操作'` 默认值改为**哨兵空串** `''`，真实标签延后到
**步骤7**（`shares`/`cash` 已定稿）按实际持仓回填：

| 条件 | 标签 |
|---|---|
| `shares > 1e-9` 且 `is_investing` | `定投中持有(NN%仓)` |
| `shares > 1e-9` 且非定投 | `持有(NN%仓)` |
| `shares <= 1e-9` | `空仓`（真空仓） |

> ⚠️ **踩坑点**：`:672` 原本拿 `== '空仓'` 当"今日尚无操作"的**哨兵判定**。
> 若只改默认值而漏掉这里，`定投结束(资金耗尽)` 分支会永久失效。已同步改为 `== ''`。

**验证：零行为变化。** 同参数重跑，与修复前磁盘 CSV 的 **12 个数值列逐行比对，
最大绝对差 ≤ 8.7e-11**（纯 CSV 浮点往返误差）；累计收益率 **128.40% 完全一致**；
全量审计仍 **9 PASS / 7 FAIL**（⏱️ 此为 2026-08-11 当时值；**2026-08-23 实跑为 8 PASS / 8 FAIL**，多出的 FAIL 是 check_J 假警报，详见 0.20-J2）。修复后 2024-09-24 正确显示 `持有(100%仓)`。

**修复后标签分布**（2020-01 组）：`持有(100%仓)` 719、`空仓` 202、
`定投(1.0×)` 168、`持有(49~52%仓)` 477、`定投(2.0×)` 8、`定投(3.0×)` 1 …

#### A. Bug J：回撤"改善"符号写反

两处输出把两个**负数**直接相减当作"改善"：`基准回撤 - 策略回撤`。
当策略回撤更浅时（如 -3.77% vs -40.51%），相减得 **-36.74%**，却标成
"改善 -36.74%" —— 方向读反。正确应为 `abs(基准) - abs(策略) = +36.74pp`。

| 位置 | 修法 |
|------|------|
| `core/performance_analysis.py` | `（回撤更浅 {abs(基准)-abs(策略):+.2f}pp）` |
| `scripts/run_multiple_backtests.py` | 同上 |

**这只是显示层 bug，不影响任何计算结果**（回撤本身算得对）。
同时把单位从 `%` 改为 `pp`（两个百分数之差是百分点，不是百分比）。
